Project Statement

Project Title

Maths Quiz

Problem Statement

Students need a simple way to practice basic mathematics through an interactive question-and-answer activity. The Maths Quiz program provides a console-based method for practicing Addition and Subtraction using multiple-choice questions.

The user selects a topic, answers questions, receives immediate feedback, and receives a final summary of their performance.

Scope of the Project

The current project is limited to two mathematics topics:

Addition

Subtraction

The project is implemented as a Python console program. It focuses on topic selection, question presentation, answer checking, randomization, and result display.

Target Users

The target users are students and beginners who want to practice basic addition and subtraction through a simple interactive quiz.

Objectives

Provide basic mathematics practice.

Make practice interactive through multiple-choice questions.

Randomize the order of questions.

Automatically check answers.

Give immediate feedback.

Stop the quiz after three incorrect answers.

Display the final performance summary.

High-Level Features

1. User Input

The program accepts the user's name.

2. Topic Selection

The user can select Addition or Subtraction.

3. Question Bank

The program contains separate question lists for Addition and Subtraction.

4. Randomization

The selected question list is shuffled using Python's random.shuffle().

5. Answer Evaluation

The user's option is compared with the stored correct option.

6. Result Tracking

The program tracks total questions attempted, correct answers, and incorrect answers.

7. Early Quiz Termination

The quiz stops when the user reaches three incorrect answers.

8. Final Result

The program displays the user's name and quiz statistics at the end.

Current Limitations

The submitted source code is a console-only program. It does not provide GUI, database or permanent score storage, user accounts, online functionality, timer, difficulty levels, progress history, or an automated testing framework. These are not part of the current source code and are therefore not described as implemented features.
